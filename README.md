Lantern Lane — a spot-the-difference game. Two near-identical pictures side by side across three hand-drawn scenes (Sunny Park, Cozy Kitchen, Harbor at Dusk) with 22 hidden differences, a countdown timer, hints, combo scoring and synthesized sounds. Pure static files under `game/` — no build step, no network requests, keyboard and mouse play.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a difference on either picture to mark it; `H` hints, `M` mutes, `R` restarts the level, `1`/`2`/`3` jump between scenes.
